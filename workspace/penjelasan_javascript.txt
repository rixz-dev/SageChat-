Apa itu JavaScript

JavaScript adalah bahasa pemrograman untuk membuat halaman web interaktif dan dinamis.

Fungsi utama:
- Mengatur perilaku halaman web di browser (klik, animasi, validasi form).
- Dipakai di frontend dengan HTML dan CSS.
- Dipakai di backend dengan Node.js.
- Dipakai untuk mobile, desktop, dan game sederhana.

Cara kerja di browser:
- Browser punya JavaScript engine (contoh: V8 di Chrome).
- Kode JavaScript dijalankan engine tanpa perlu kompilasi manual.
- JavaScript bisa ubah DOM (struktur HTML) secara langsung.

Contoh kode:
console.log("Halo, JavaScript");
document.getElementById("judul").innerText = "Halo";

Ciri penting:
- Berbasis objek, event, dan asynchronous.
- Mendukung callback, promise, async/await.
- Ekosistem besar: React, Vue, Angular, Express, Next.js.

Bedanya dengan Java:
- Nama mirip, bahasa beda.
- JavaScript untuk web dan ringan, Java untuk umum dan compiled.

Kesimpulan:
JavaScript wajib untuk web modern karena bikin web hidup, cepat, interaktif.
